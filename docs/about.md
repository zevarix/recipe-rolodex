# About the Rolodex

The best recipes are the ones that make it into the regular rotation.

**Recipe Rolodex** is a simple public cookbook for the meals we cook, adapt, and want to remember. It's maintained in Markdown on GitHub and published with Zensical. Every page is intended to be readable on a phone next to the stove—and on paper when that's easier.

The first collection came from a family dinner: jumbo shrimp, basil pesto pasta, Grandpa's garlic bread, and a small bowl of clam chowder before the main course.

### Our recipe rules

- Give real measurements and an honest serving count.
- Write cooking steps in the order they'll actually happen.
- Separate homemade recipes from purchased ready-to-heat ingredients.
- Record tweaks worth repeating, not just perfect-looking meals.
- Keep family privacy and image rights in mind when adding anything to this public site.

If you have an idea, see [How to contribute](https://github.com/zevarix/recipe-rolodex/blob/main/CONTRIBUTING.md).
